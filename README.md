# ReVeste – Plataforma de Moda Circular

O **ReVeste** é uma aplicação web Full-Stack desenvolvida em ASP.NET Core MVC para incentivar a economia circular através de um sistema de créditos virtuais.

A proposta converte o guarda-roupa ocioso em moeda de troca, incentivando o consumo consciente, reduzindo o desperdício têxtil e promovendo a economia circular através de uma plataforma acessível e prática.

## ⚙️ Destaque Técnico: Algoritmo de Valoração de Créditos

O núcleo da aplicação utiliza uma lógica parametrizada nas Controllers do ASP.NET Core capaz de processar múltiplas variáveis de entrada (marca, tipo de peça e estado declarado de conservação) para calcular e converter o resultado em moedas virtuais em tempo real, atribuindo automaticamente a quantidade de créditos adequada a cada peça.
